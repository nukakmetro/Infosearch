Python 3.11
Открыть через pycharm проект -> запустить

Была разработана поисковая система на основе векторной модели поиска. Каждый документ из коллекции представлен в виде вектора весов TF-IDF, сформированного по файлам result_tokens или result_lemmas. Пользовательский запрос также преобразуется в вектор, где для каждого слова вычисляется вес на основе TF и IDF. Для оценки релевантности документа запросу используется косинусная мера сходства. После вычисления степени близости для всех документов результаты сортируются по убыванию, и пользователю выводятся наиболее подходящие документы.

 Разработанная поисковая система находится в 5Task/VectorSearchEngine.py
