# Task 4
Python 3.11
Открыть через pycharm проект -> запустить

В рамках задания была реализована обработка текстовой коллекции, состоящей из 100 документов, представленных в виде токенов и лемматизированных форм.

Для каждого документа из папок tokens и lemmas были выполнены следующие действия:
	2.	Для каждого слова в документе рассчитана метрика tf.
	3.	Для всей коллекции документов рассчитана метрика idf.
	4.	Для каждого слова в каждом документе вычислена итоговая метрика tf-idf.
	5.	Результаты сохранены в отдельные текстовые файлы:
	•	для терминов — в папку result_tokens
	•	для лемматизированных форм — в папку result_lemmas
